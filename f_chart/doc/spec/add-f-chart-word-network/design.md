## Context

词网络与 M62 节点-链接图结构相近，但语义不同：词网络的节点半径承载词频信息，标签置于节点内部而非下方，配色按词分组缺失时统一使用主题色。为避免改动既有实现，新建独立文件，同时复用已沉淀的力导向迭代思路与 `nodeLinkWidth`。

## Decisions

### 数据模型

- `nodes` 必填且非空；`id` 唯一；`name` 缺省取 `id`；`weight` 缺省为 `1` 且必须大于 0。
- `links` 必填；`source` / `target` 必须存在于节点表；`value` 缺省为 `1` 且必须大于 0。
- `layout` 默认 `force`，支持 `circular`；`linkDistance` 默认 `100` 且必须大于 0。

### 半径

`wordNetworkRadius(weight, maxWeight) = 8 + 10 × sqrt(weight / maxWeight)`，即 `[8, 18]`。

### 布局

- `circular`：节点均匀分布在绘图区中心、半径取短边 35% 的圆周上。
- `force`：先以圆形布局初始化，再执行 80 轮斥力 / 弹簧 / 回中迭代，与 M62 相同的确定性参数，不做随机初始化。

### 绘制

- 连线先画，节点后画，保证节点覆盖线端。
- 节点标签水平居中、垂直居中，字号随半径线性映射到 `[10, 15]`。
- 节点颜色按 `name` 散列取主题色，使同一词在不同图中颜色稳定。

## Risks

- 力导向迭代在节点较多时计算量为 O(80n²)，与 M62 一致；词网络规模通常较小。
- 标签可能超出小节点边界；字号上限 15px 并配合垂直居中缓解。

## Testing

- 覆盖节点/连线数量、半径单调性与边界、圆形布局、非法布局、悬空连线、重复 id、非正权重与类型不匹配。
- 全量回归在签名后执行 `cjpm test --skip-build`。
