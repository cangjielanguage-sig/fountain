# Design

## 1. 轴

`ChartConfig.yAxis2` 可选。`ChartFrame` 接收 `rightLabelWidth` 收缩绘图区，并新增 `drawYAxisRight`（刻度在右侧，不重复画网格）。

## 2. 柱分组

按 `stack` 分组：空 `stack` 的单系列各自成组；非空同键成组。每组占一个子槽；组内单系列画普通柱，多系列堆叠；百分比组按 `abs` 归一化。

## 3. 叠加

绘制顺序：柱 → 折线 → 散点。折线/散点按 `axis` 选择左右比例尺；散点 x 先映射为类目下标，再用 `band.center`。

## 4. 范围

左右轴分别计算：柱组按类目总和（或 100%）、非堆叠柱按单值、折线按点值、散点按 y。柱参与时范围包含 0；最后走 `lineRange` 留 5%。
