# Design

## 1. 数据

每系列解析 `name`（缺省取 `variables[i]`）与 `data`（`{x,y}` 数组），按 `x` 升序排序。

## 2. 轴

- x 轴覆盖全部数据，两侧各留 3%。
- y 轴覆盖全部系数，上下各留 5%，并包含 0（零系数参考线）。
- 支持 `xAxis` / `yAxis` 的 `min`、`max`、`values`。

## 3. 绘制

- 每系列一条 1.5px 折线，颜色取主题调色板。
- 数据点半径 2.5px，同色。
- 零线为 `#e0e0e0` 实线，位于 `y = 0`。

## 4. 校验

`series` 为空、`data` 为空、`x`/`y` 非数字均抛 `ChartException`。
