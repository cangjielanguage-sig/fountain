# Design

## 1. 校验

方阵、每阶非空、元素有限且在 [-1,1]；`xAxis.labels` / `yAxis.labels` 非空时必须与阶数一致。

## 2. 布局

- 矩阵区域取正方形：可用宽高取较小值。
- 左上角留出 y 标签列与标题区；行标签右对齐、列标签居中。

## 3. 颜色

- `value < -0.33` → low；`value <= 0.33` → mid；否则 high。
- 默认 `["#d73027", "#ffffff", "#4575b4"]`。

## 4. 文本

- `showValues` 时在单元中心显示两位小数，绝对系数大于 0.5 用白字，否则深灰。
