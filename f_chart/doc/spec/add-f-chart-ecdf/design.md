# Design

## 1. 数据

每系列解析 `data`（非空数字数组）；排序后累计频率为 `(i + 1) / n`。

## 2. 坐标

- x 轴 `LinearScale`，范围覆盖全部观测值，缺省两侧各留 2%。
- y 轴 `LinearScale`，范围缺省 0 到 1。
- 阶梯路径：首点从 `(x0, 0)` 起，先垂直跃升到 `(x0, 1/n)`，再水平到 `(x1, 1/n)`，依次推进。

## 3. 绘制

每系列一条 2px 折线，颜色取主题调色板；不画数据点。图例按系列名输出。

## 4. 校验

`series` 为空、`data` 为空、元素非数字均抛 `ChartException`。
