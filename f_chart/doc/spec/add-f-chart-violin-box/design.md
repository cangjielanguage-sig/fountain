# Design

## 1. 分组与统计

- 分组规则与 `ViolinChart` 一致：嵌套数组多组，扁平数组单组。
- 每组排序后计算 Q1 / 中位数 / Q3，并用 1.5 IQR 栅栏确定须线端点。
- 栅栏外的样本为异常值。

## 2. 密度轮廓

- 带宽缺省用 `defaultBandwidth(values)`。
- 在 y 轴范围上取 41 个采样点，用 `gaussianKde` 计算密度，镜像成闭合路径，最大半宽为槽宽的 0.4 倍。
- 轮廓填充系列色，透明度 0.35。

## 3. 箱体叠加

- 箱体宽为槽宽的 0.12 倍，白底描边。
- 中位线加粗；须线从 Q1 下栅栏内最小值到 Q3 上栅栏内最大值，端帽宽为箱宽。
- 异常值画半径 3px 的圆点，颜色与系列一致。
