# Design

## 1. 树构建

与火焰图相同：解析全部节点、按 `parent` 挂接、校验唯一根、父值不小于子值之和、检测环。

## 2. 子树选择

- `root` 缺省时取整棵树的根；否则按 id 查找，找不到抛 `InvalidValue`。
- 从选中节点开始重新计算相对深度（选中节点深度为 0）。
- 宽度以选中节点的 value 为基准归一化。

## 3. 深度截断

`maxDepth` 缺省不限；提供时只绘制相对深度不超过该值的节点，但仍递归遍历以计算布局。

## 4. 绘制

自底向上布局，颜色按名称经 `flameColorIndex` 映射；宽度足够时写节点名，class `offline-flame-label`。
