# Design

## 1. 结构

- 优先用 `edges` 建立父子关系；`edges` 为空时按 `parent` 字段建树。
- 根为没有入边的节点；必须恰好一个。
- 校验边端点存在、节点 id 唯一、无重复父节点。

## 2. 布局

- `decisionTreeLayout` 与组织图一致：叶子依次占槽，父节点取子节点槽位中点。
- 节点宽 140、高 44，层级间距 70，水平间距取 20。

## 3. 绘制

- 内部节点填充主题色、白字；叶子填充 `#e8f5e9`、深色文字，并加 8px 圆角。
- 连线为从父底中点到子顶中点的正交折线，标签写在折线中点右侧。

## 4. 校验

`nodes` 为空、id 重复、边端点未知、根数量不为 1 均抛 `ChartException`。
