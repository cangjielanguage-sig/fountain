# Design

## 1. 数据

- 首个元素为数组 → 嵌套模式，每组一个数组；否则视为单组扁平数组。
- 每组名称取 `xAxis.labels[i]`，缺省用序号。
- 每组至少一个数值。

## 2. 轮廓

- 对每组计算带宽（显式或 Silverman）。
- 在 y 轴绘图范围内取 40 个采样点，计算 `gaussianKde`，按该组最大密度归一化。
- 轮廓最大半宽为 `bandWidth * 0.4`；右侧从上到下、左侧从下到上闭合。

## 3. 箱体

- 排序后取 0.25 / 0.5 / 0.75 分位。
- 箱宽 `bandWidth * 0.1`，class `box`；中位线 class `median`。

## 4. 轴与颜色

- y 范围覆盖所有组数据并留 5% 余量；特殊值轴范围显式覆盖。
- 颜色取 `series[].color` 或调色板首位；填充透明度 0.35。
