## Context

词云需要在有限画布内摆放不同字号、不同旋转方向的词项。SVG 无原生文本测量，仓库统一使用 `chartTextWidth` 估算宽度（CJK 1em、其他 0.56em），因此布局必须基于估算值做确定性排布，避免随机性导致测试不稳定。

## Decisions

### 字号映射

- 以词表权重的最小/最大值做区间归一化，再取平方根映射到 `[minFontSize, maxFontSize]`，抑制极端权重造成的字号断层。
- 权重全部相同时统一取 `minFontSize`，避免除零。

### 布局

- 词项按权重降序排序，权重相同保持输入顺序。
- 采用货架式（shelf）布局：从左到右依次放置，当前行剩余宽度不足时换行；行高取该行最高词项的高度。
- 旋转 90°/-90° 的词项按「宽 = 字号、高 = 文本宽度」占位。
- 若某个词放入后超出绘图区底部，其后词项停止绘制，保证输出稳定。

### 旋转

- `rotate` 数组按排序后的词序循环取值。
- 支持 `0`、`90`、`-90`；其他角度视为非法。

### 配色

- 词项未提供 `color` 时按序号取主题调色板颜色。

## Risks

- 估算宽度与真实字体宽度存在偏差，长词可能轻微越界；通过货架换行与绘图区裁剪缓解。
- 词量很大时部分词被丢弃；这是确定性布局的取舍，文档已说明。

## Testing

- 覆盖词项数量、字号边界、旋转循环、颜色覆盖、空词表、非法字号、非法权重与类型不匹配。
- 直接测试 `wordCloudFontSize` 的开方映射。
- 全量回归在签名后执行 `cjpm test --skip-build`。
