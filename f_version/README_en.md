# f_version

## STDX dependency

Configure the environment variable: `export CANGJIE_STDX_DYNAMIC_PATH=/path/to/dynamic_stdx`

This module provides the framework with the version number of the application project, the version number of the fountain utility library, and the process startup time.

## fountain version number

```cj
//When building fountain with fboot, the version number is replaced with the latest one
public const Version = "1.3.7"
public const FountainVersion: String = "fountain(" + Version + ")"
```

`Version` is a constant written by `fboot version x.y.z` or by the `cangjie.sh` script at release time; do not change it by hand.

## Application project version number

Building an application project with fboot creates a module and fills the project version into this module. `fountain::f_app.App` reads the project name and version number from this module.

```cj
public struct AppVersion {
    /**Called by the application information module generated by fboot; should be called only once per process*/
    public static func set(banner: String, name: String, version: String): Unit
    /**The startup BANNER of the application; an empty string when set has not been called*/
    public static prop banner: String
    /**Application name; an empty string when set has not been called*/
    public static prop name: String
    /**Application version number; an empty string when set has not been called*/
    public static prop version: String
}
```

When `set` has not been called, the three properties of `AppVersion` return empty strings (they do not throw), so the caller must check for emptiness itself. The `%app` and `%appver` placeholders of `f_log` take their values from these three properties.

## Process startup time

```cj
/**Evaluated when the f_version package is initialized; serves as the starting point for application startup timing*/
public let AppStarts: MonoTime
```

`AppStarts` is a top-level `let`, evaluated when the `f_version` package is initialized; `f_app` uses it to compute the application startup time.
