### [x] P1-1: ConsumerMatcher.register() 缺重复检查 ✅ 已完成

- **问题等级**: P1
- **问题描述**: 相同 consumerId 可重复注册，deregister 只移除一次
- **修复方案**: register 先查找已有 consumerId，存在则更新而非追加
- **实施难度**: 低

- **新增测试**: `testDuplicateRegisterNoDuplicates` — 相同 consumerId 二次注册不产生重复
- **新增测试**: `testDuplicateRegisterDifferentConsumerId` — 不同 consumerId 各自保留

### [x] P1-3: QueueManager.queues HashMap 无并发保护 ✅ 已完成

- **问题等级**: P1
- **问题描述**: queues HashMap 被多线程并发读写，所有 public 方法均有竞态
- **修复方案**: HashMap → ConcurrentHashMap + Mutex 保护 ArrayList 值变异
- **实施难度**: 中

#### 经验总结
- HashMap 替换为 ConcurrentHashMap 解决 map 级别的并发安全
- Mutex(`lock`) 保护所有涉及 `ArrayList<Queue>` 值变异的完整方法体（createQueues、destroyQueues、reassign、drainCompleteCheck 等）
- `getQueues()` 返回防御性拷贝防止调用者意外修改内部列表
- `startAll()` / `close()` 在锁内快照队列列表，锁外执行线程启动和关闭
- **新增测试**: `testConcurrentCreateAndListTopics` — 10 线程并发创建+查询+列表
- 42 测试全部通过
