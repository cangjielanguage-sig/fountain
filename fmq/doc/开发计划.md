## 阶段 4：消费者投递

**依赖**：阶段 3

**涉及文件**：

```

├── consumer_matcher.cj — ConsumerMatcher 消费者匹配
└── delivery.cj         — DeliveryRecord 管理 + 重试 + ACK 超时
```

### 4.1 consumer_matcher.cj

```cangjie
public class ConsumerMatcher {
    // 刷新消费者注册缓存（从 fleet /mq/consumes 读取）
    public func refresh()

    // 匹配消费者
    // 返回值：map[groupId → consumerId]
    public func match(message: Message): HashMap<String, String>

    private func matchesTopic(mode: MatchMode, topic: String): Bool
    private func roundRobinSelect(consumers: ArrayList<ConsumerRegistration>): ConsumerRegistration
}
```

匹配流程：

```
match(message)
  → 遍历所有注册的消费者
  → matchesTopic(reg.matchMode, message.topic) 筛选
    → Exact(pattern): pattern == topic
    → Glob(pattern):  PathPattern(pattern).matches(topic)
    → Prefix(pattern): topic.startsWith(pattern)
  → 按消费者组分组
  → 每组 Round-Robin 选一个
  → 返回 { groupId → consumerId }
```

### 4.2 delivery.cj

```cangjie
public class DeliveryManager {
    // 记录投递
    public func recordDelivery(messageId, consumerId, groupId): DeliveryRecord

    // ACK 处理
    public func onAck(messageId: MessageID): Bool

    // 超时扫描（由读线程调用）
    public func checkTimeout(now: DateTime): ArrayList<DeliveryRecord>

    // 重试
    public func retry(record: DeliveryRecord, consumerMatcher: ConsumerMatcher): Bool

    // 获取消费者组 offset
    public func getOffset(topic: String, queueIndex: Int64, groupId: String): Int64

    // 持久化 offset 到 fleet
    public func persistOffset(topic: String, queueIndex: Int64, groupId: String, offset: Int64)
}
```

重试流程：

```
checkTimeout() → 筛选超时记录
  for each 超时记录:
    if retryCount < mq_max_retry_count (3):
      → 重投（原消费者在线则原消费者，否则同组另一消费者）
      → retryCount++
      → 重新计时
    else:
      → 移入死信队列（DeadLetterStore.append()）
```

```cangjie
// 消费循环（后台 Pull 线程），支持 dataFilter 数据过滤
public class ConsumerLoop<T> where T <: DataFields<T> {
    let groupId: String
    let callback: (Message) -> Unit

    public func run(): Unit {
        while (!closed) {
            let msg = poll(timeout: Duration.second * 1)
            if (let Some(m) <- msg) {
                callback(m)
                ack(m.id)
            }
        }
    }

    private func poll(timeout: Duration): ?Message {
        // 发送 CONSUME 命令
        // 等待 RESP 返回消息
    }
}

// 边解码边过滤：使用 f_codec 将 Array<Byte> 解码为 T，同时用 DataPath 匹配
private func dataFilterMatch<T>(payload: Array<Byte>, filter: ?String): Bool where T <: DataFields<T> {
    if (filter == None || filter.value == "") { return true }
    let decoder = DefaultCodec.getDecoder()
    let data = decoder.decodeFromBytes<T>(payload)
    return PathPattern(filter.value).test(data)
}
```

消费循环的数据过滤流程：

```
收到消息 → labelsFilter(msg) && dataFilterMatch<T>(msg.payload, dataFilter)
  ├── true  → onMessage callback → ACK
  └── false → ACK（跳过该消息）
```
