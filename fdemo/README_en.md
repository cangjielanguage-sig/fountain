# Additional notes before you start
Developing with fountain needs no main function: initialize a project developed with fountain as a workspace, compile every module into a dynamic library, and it can be started.
Before starting:
- First run `cjpm install "fountain::fboot"=<a.b.c> --root </path/to/install>`
- Then run `fboot build` in the workspace directory of the application project
- Finally run `fboot run --dylibPattern=<regex matching the file names of the project dynamic libraries to load>`
  - Only dynamic library files whose names match this regular expression are loaded
  - The dynamic libraries that usually need to be loaded include:
    - the controller package
	- the service.impl package
	- the initialization package
	  - If all initialization depends on scripts and environment variables, the initialization package can be omitted
	  - If there is extra initialization work that cannot be satisfied by environment variable configuration, such an initialization package is needed (see the boot package of fdemo for details)
    - If the cron jobs live in a separate package, the regular expression must also cover the dynamic libraries of those jobs
	- `fdemo/boot.sh` has a corresponding example

# Preparation before compiling
1. Set the path of the stdx dynamic libraries as the environment variable `CANGJIE_STDX_DYNAMIC_PATH`
2. Run the following commands
```bash
export CANGJIE_STDX_PATH=$CANGJIE_STDX_DYNAMIC_PATH
export POSTGRES=url_of_postgres
```
