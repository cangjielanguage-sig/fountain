# 安装依赖
```bash
pip install fastapi uvicorn pydantic FlagEmbedding
```
## 安装BGE-M3
service.py首次执行时会自动下载BGE-M3模型，请耐心等待。


##  PyTorch 安装（任选其一）
|硬件平台|安装命令|
|:----:|:----:|
|CPU 版|	pip install torch --index-url https://download.pytorch.org/whl/cpu|
|NVIDIA GPU (CUDA 11.8)|	pip install torch --index-url https://download.pytorch.org/whl/cu118|
|NVIDIA GPU (CUDA 12.1)|	pip install torch --index-url https://download.pytorch.org/whl/cu121|
|昇腾 NPU|	需要先安装 CANN 工具包，然后：pip install torch==2.2.0 torch_npu==2.2.0（版本需与 CANN 配套，详见 [Ascend 官方文档](https://www.hiascend.com/)）|

# 启动
```bash
python bge_m3_service.py
```

```bash
PORT=8080 python bge_m3_service.py
```

# 访问

```bash
curl -X POST "http://localhost:8000/embed" \
     -H "Content-Type: application/json" \
     -d '{
           "texts": ["今天天气真好", "BGE-M3 is powerful"],
           "max_length": 256
         }'
```
