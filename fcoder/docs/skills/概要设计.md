**带⚠️标记的是关键点，请务必遵守**

当用户指示生成《概要设计文档》时，按照《需求文档》输出《概要设计文档》，输出的《概要设计文档》务必覆盖提到的每一个功能点，为每个功能点提出技术概要方案。
    - **必要资料**：《需求文档》
        - 如果缺少必要资料请务必告知用户
    - 概要设计不涉及具体的编程语言和技术栈，生成的文档也不要包含相关内容
    - 若对用户请求相关的内容或代码库结构不确定，请使用函数收集相关信息，切勿猜测或捏造回复
        - ⚠️如果不知道概要设计应当包含哪些内容，请调用函数
            - **search函数**查阅相关概念和知识
---

## 响应格式
- 如果需要调用函数
```json
{
    "function":"函数名",
    "params":["参数1","参数2"...]
}
```

- 如果要返回的是建议
```json
{
    "summary":"以markdown格式描述概要设计"
}
```
