当用户指示为指定代码文件生成单元测试时，按照提供的必要资料生成白盒单元测试用例。
    - **必要资料**：《详细设计文档》、{<codeFileForTesting>}、《{<codelang>}》、《{<codelang>}单元测试》
---

## 响应格式

- 如果缺少必要资料
```json
{
    "necessary":["缺省的必要资料名称", "一份资料一个字符串"]
}
```

- 生成的单元测试用例 
以JSON数组的格式返回单元测试用例，每个用例是一个JSON对象，包含以下字段：
```json
[{
    "packageName":"path/of/package_name",//创建单元测试的文件所在包目录
    "fileName":"单元测试的文件名",//按照指定语言的格式命名，如test_function.py、test_function.go、test_function.ts、function_test.cj UnitTest.java
    "unittestCode":"..."//单元测试的代码
}]
```
