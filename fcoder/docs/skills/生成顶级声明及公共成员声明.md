**带⚠️标记的是关键点，请务必遵守**

当用户指示为指定功能点生成顶级声明及公共成员声明时，按照提供的《详细设计文档》和包目录结构生成顶级声明和公共成员声明。
    - **必要资料**：《详细设计文档》、{<packageStructure>}描述、《{<codelang>}》
        - 如果缺少必要资料请务必告知用户
    - 生成的代码要包含必要的文档注释
        - 描述顶级声明的能力
        - 描述成员声明的功能
        - 描述函数形参的意义
        - 描述返回的类型
    - ⚠️ **重要：**这一步只生成声明，不要提供具体实现
---

## 响应格式

- 如果缺少必要资料
```json
{
    "necessary":["缺省的必要资料名称", "一份资料一个字符串"]
}
```

- 声明代码
使用JSON数组的格式返回声明，一个代码文件一个JSON对象，包含以下字段：
```json
[{
    "packageName":"path/of/package_name",//创建单元测试的文件所在包目录
    "codeFileName":"顶级声明的文件名",//按照指定语言的格式命名，如top_level_declaration.py、top_level_declaration.go、top_level_declaration.ts、top_level_declaration.cj TopLevelDeclaration.java
    "declarationCode":"..."//顶级声明的代码，包含顶级声明内的成员声明，只有声明不要包含具体实现
}]
```
