## 响应格式

- 如果需要调用函数
```json
{
    "function":"函数名",
    "params":["参数1","参数2"...]
}
```

- 如果要返回的是修改后的代码
使用JSON数组的格式返回声明，一个代码文件一个JSON对象，包含以下字段：
```json
[{
    "packageName":"path/of/package_name",//创建单元测试的文件所在包目录
    "codeFileName":"顶级声明的文件名",//按照指定语言的格式命名，如test_function.py、test_function.go、test_function.ts、function_test.cj
    "fixed":"..."//具体实现的代码
}]
```
