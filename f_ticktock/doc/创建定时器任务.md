## 创建定时器任务
```cj
import fountain::f_ticktock.*
import fountain::f_bean.*
import fountain::f_bean.macros.*

@Bean
public class TickTockTask <: CronTicktockTask {
    public prop cron: String {
        get() {
            '1/3-45 * * * * * *'//CRON表达式后面的*可以省略，即这个表达式可以改成1/3-45
        }
    }
    public func execute(): Unit {
        ...//定时任务逻辑
    }
    /**
     * 是否只执行一次的任务，需要只执行一次的重写这个方法
     *
     * @return true表示只执行一次，false表示执行多次。可以不实现这个函数，默认是false
     */
    public prop once: Bool {
        get() {
            return false
        }
    }
    /**
     * 是否可以并发执行任务
     *
     * @return true表示可以并发执行，false表示不可以并发执行。并发执行指的是上次任务的执行状态不会影响下次执行周期到达时是否执行。可以不实现这个函数，默认是false
     */
    public prop concurrentable: Bool {
        get() {
            return false
        }
    }
    /**
     * 当前任务是否正在执行
     *
     * @return true表示正在执行，false表示没有执行。开发者可以实现新的判断逻辑。可以不实现这个函数，有默认判断逻辑
     */
    public func executing(stamp: Int64): Bool {
        return DefaultTicktockTaskExecuting.executing(name, stamp)
    }
    /**
     * 重置执行状态。开发者可以实现新的判断逻辑。可以不实现这个函数，有默认判断逻辑
     */
    public func reset(stamp: Int64): Unit {
        DefaultTicktockTaskExecuting.reset(name, stamp)
    }
    /**
     * 任务名称。默认是定时任务实现类型的全限定名
     */
    public public open prop name: String {
        get() {
            ClassTypeInfo.of(this).qualifiedName
        }
    }
    public func toString(): String {
        return this.name
    }
}
```

### CRON表达式
每个时间单位都支持一样的语法，从左到右依次为：秒（SECONDLY）、分（MINUTELY）、时（HOURLY）、日（MONTH_DAILY）、月（MONTHLY）、周（WEEK_DAILY）、年（YEARLY）
- `*` 表示任意值
- `start-end` 表示在当前时间单位的时间范围，start是CRON表达式中当前时间单位的起始值，end表示结束值，取值范围是前闭后闭区间
- `start/step` start是CRON表达式中当前时间单位的起始值，end表示从起始值开始的时间间隔
- `start/step-end` start是CRON表达式中当前时间单位的起始值，step是从起始值开始的时间间隔，end表示结束值，取值范围是前闭后闭区间
- `,` 是CRON表达式中当前时间单位的多个值或多种表达方式的列表
  - `1,3,4,6,9`，表示任意一个值，当前时间在当前时间单位只要是其中一个值当前时间在当前时间单位就算满足条件
  - `1,3,5-10,12/3,15/2-45`，多种表达方式可以用`,`分隔，当前时间在当前时间单位只要满足任意一个表达式，当前时间在当前时间单位就算满足条件
- `L` 表示CRON表达式中当前时间单位的最后一个值，注意不是最大值。对于MONTH_DAILY，由于每个月份的天数不同，每个月的最后一天并不一样。
- 在同一个时间单位中可以用`,`分隔多种表达式
- `*/`、`*`、`*/*`、`*-*`、`*/*-*`、`*/1-*`、`*/1`、`min/*`、`min/*-*`、`min-*`、`min/1`、`min/1-*`、`*/*-max`、`*/1-max`、`*-max`、`min/*-max`、`min/1-max`、`min-max`
   - 这些表达方式都是一样的，意思是从当前时间单位的最小值到最大值的每一个值
- CRON表达式尾部的`*`可以省略

### 延迟任务
延迟任务是指任务注册到定时器延迟多长时间以后执行。
```cj
public abstract class DelayedTicktockTask <: CronTicktockTask {
    /**
     * 延迟任务的执行模式
     * DelayedPeriodic 是一个枚举，有两个取值：
     *   - FixedRate 固定执行频率，每次开始执行时间间隔一致，不论上次执行j 否执行完成，下次执行时间间隔一致
     *   - FixedDelay 固定执行间隔，两次相邻执行的时间间隔一致，绝不重叠执行，上次执行结束后间隔指定时间后再进行下次执行
     */
    public prop delayedPeriodic: DelayedPeriodic 
    /**
     * 任务注册到定时器是否立即执行
     */
    public prop immediate: Bool 
    /**
     * 延迟执行的时间间隔
     */
    public prop delay: Duration 
    /**
     * 定时任务逻辑
     */
    public func execute(): Unit 
}
```
