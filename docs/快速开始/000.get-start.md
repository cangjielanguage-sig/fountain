# Fountain 使用手册

## 快速开始
### 概述
#### 简介
本指南提供了 Fountain 如何帮助您加速应用程序开发的示例。当您阅读更多相关指南时，您将看到 Fountain 的更多用例。本指南旨在让您快速体验 Fountain。

#### 您将构建什么
您将使用 Fountain 构建一个简单的 Web 应用程序，并为其添加一些有用的服务。

#### 您需要什么
- 时间要求：约20分钟
- 开发工具：文本编辑器或 IDE（推荐：VSCode）
- 所需依赖：
    - 仓颉SDK：cangjie-sdk-linux-x64-1.0.3
    - 仓颉Stdx：cangjie-stdx-linux-x64-1.0.3.1

#### 如何完成本指南
与大多数技术入门指南一样，您可以从头开始并完成每个步骤，也可以绕过您已经熟悉的基本设置步骤。无论哪种方式，您最终都会得到可运行的代码。

---
具体步骤如下：
1. 进入 fdemo 目录。
2. 修改 fdemo 目录下的 cjpm.toml 配置文件：
    - 仓颉提供了两种依赖引入方式：git 远程依赖和本地路径依赖。
    - 取消 git 远程依赖的注释，将本地路径依赖进行注释，配置内容如下：
      ```toml
      [dependencies]
        fountain = {path = "../"}
        opengauss = {git = "https://gitcode.com/runningW/opengauss-driver.git", branch="master"}
      #  opengauss = {path = "../../opengauss-driver"}
      ```
3. 修改数据库连接配置（fdemo/boot/src/boot.cj）：
    - 将 url 修改为本地 pgsql 实例的连接地址，代码如下：
      ```cj
      let url = env.getVariable('POSTGRES') ?? 'postgres://postgres:123456@127.0.0.1:5432/postgres?sslmode=disable'
      ```
4. 进行项目构建，执行命令：`./boot.sh build ./fdemo`
5. 运行项目，执行命令：`./boot.sh run ./fdemo`
6. 输入网址 `http://127.0.0.1:8080/helloworld`，页面显示“helloworld”，说明启动成功。

## 快速搭建基于 Fountain 的项目
本指南详细介绍了如何快速搭建一个使用 Fountain 框架并以动态库（Dynamic Library）形式构建的项目。

### 1. 项目初始化和目录结构
首先，创建项目根目录并初始化主项目（fountain_demo）和子模块（user），具体步骤如下表：

| 步骤 | 命令 | 描述 |
| ---- | ---- | ---- |
| 1.1 | `mkdir fountain_demo` | 创建项目主目录。 |
| 1.2 | `cd fountain_demo` | 进入项目目录。 |
| 1.3 | `cjpm init --type dynamic` | 初始化主项目为动态库类型。 |
| 1.4 | `mkdir user` | 创建子模块目录。 |
| 1.5 | `cd user` | 进入子模块目录。 |
| 1.6 | `cjpm init --type dynamic` | 初始化子模块为动态库类型。 |
| 1.7 | `cd ..` | 返回主项目目录。 |

### 2. 配置 cjpm.toml 文件
项目中有两个 cjpm.toml 文件需要配置：主项目（fountain_demo/cjpm.toml）和子模块（fountain_demo/user/cjpm.toml）。

#### 2.1 主项目配置
请将以下内容复制并替换 fountain_demo/cjpm.toml 的内容。注意：确保 `/home/xiaohe/workspace/fountain` 是您本地 Fountain 源码的实际路径。

```toml
[dependencies]
  # 配置本地的 fountain 项目路径
  fountain = {path = "/home/xiaohe/workspace/fountain"}

## Linux 环境配置
### 环境准备
#### 仓颉环境配置
1. 参考 [https://cangjie-lang.cn/docs?url=%2F1.0.1%2Fuser_manual%2Fsource_zh_cn%2Ffirst_understanding%2Finstall_Community.html](https://cangjie-lang.cn/docs?url=%2F1.0.1%2Fuser_manual%2Fsource_zh_cn%2Ffirst_understanding%2Finstall_Community.html) 进行配置。

#### Stdx 环境配置
1. 本项目依赖仓颉Stdx包，参考 [https://gitcode.com/Cangjie/cangjie-stdx-bin/releases?isLogin=1](https://gitcode.com/Cangjie/cangjie-stdx-bin/releases?isLogin=1) 进行配置。

#### Fountain 环境配置
1. 克隆 Fountain 源代码至本地环境，执行命令：`git clone -b lts/1.0.0 https://gitcode.com/Cangjie-SIG/fountain.git`
2. 安装 fboot 项目依赖，在 fboot 目录下执行：`cjpm install`
3. 将 Fountain 动态链接库所在的路径加入环境变量，执行命令：`export FOUNTAIN_HOME=~/.cjpm/libs/fboot`
4. 将编译后的动态链接库加入环境变量，执行命令：`export LD_LIBRARY_PATH=$FOUNTAIN_HOME:$LD_LIBRARY_PATH`

#### 环境配置参考（.bashrc）
```
export CANGJIE_HOME="/home/user/cangjie/cangjie"
export CANGJIE_STDX_PATH="/home/user/cangjie/stdx/1.0.3.1/linux_x86_64_llvm"
export CANGJIE_STDX_DYNAMIC_PATH="/home/user/cangjie/stdx/1.0.3.1/linux_x86_64_llvm/dynamic/stdx"
export FOUNTAIN_HOME="/home/user/.cjpm/libs/fboot"
export LD_LIBRARY_PATH=$FOUNTAIN_HOME:$LD_LIBRARY_PATH

#### 2.2 子模块配置
请将以下内容复制并替换 fountain_demo/user/cjpm.toml 的内容。

```toml
[package]
  cjc-version = "1.0.0"
  name = "user"
  description = "Fountain user module"
  version = "1.0.0"
  target-dir = ""
  src-dir = ""
  output-type = "dynamic"
  compile-option = "-O2 --dy-std"
  override-compile-option = "-O2 --dy-std"
  link-option = ""
  package-configuration = {}
```

### 3. 创建控制器文件
在 user 模块中创建源代码文件，实现一个简单的 Web 控制器，具体步骤如下表：

| 步骤 | 命令 | 描述 |
| ---- | ---- | ---- |
| 3.1 | `mkdir -p user/src` | 创建 user/src 目录。 |
| 3.2 | `touch user/src/HellowordController.cj` | 创建控制器源文件。 |

将以下内容写入 fountain_demo/user/src/HellowordController.cj：

```cj
package user

import fountain.mvc.*
import fountain.mvc.macros.*

@Controller
public class HellowordController {
    
    /**
     * 定义一个 GET 请求处理器，路径为 /
     * 生产纯文本内容
     * 忽略安全检查（仅作示例，实际项目中请谨慎使用）
     */
    @GetMapping[path:"/", produces:'text/plain']
    @IgnoreSecurity
    public func helloworld(): String {
        return "helloworld"
    }
}
```

### 4. 项目构建与运行
在项目根目录（fountain_demo）下执行构建和运行命令。

#### 4.1 构建项目
| 命令 | 描述 |
| ---- | ---- |
| `fboot build out` | 构建项目，并将编译后的结果输出到名为 out 的目录中。 |

#### 4.2 运行项目
| 命令 | 描述 |
| ---- | ---- |
| `fboot run ./ --dylibPattern='user'` | 基于 Fountain 框架运行当前项目（默认使用 out 目录中的编译产物）。 |

**参数说明**：`--dylibPattern='user'` 指定要加载的动态库（dylib）匹配模式。在本例中，它指示 Fountain 仅加载名称中包含 'user' 的动态库（即 user 模块编译生成的动态库）。

#### 4.3 验证结果
项目成功启动后，您可以通过访问以下地址来验证控制器是否正常工作：
- 访问地址：`http://localhost:8080/`
- 预期输出：`helloworld`
