## §0 总览与设计原则

**需求**：世界内**异构数据**——`List<Any>`、`Map<String, Any>`、`Map<Int64, Any>`：容器与局部可持"类型开放"的值，用 `is` / `as` 做类型问答与取出。HostObject（M2 §11）要求内容按类型化类声明封闭，覆盖不了开放内容；边界 `Any`（`call<T>` 的 Marshal）只在桥存在、不进入世界内计算。

**继承**：M1 全部硬不变式（I1–I8）与 M2 全部语义原样生效。本稿按 M1 §13.3 规则**扩展**白名单：+3 helper（H63–H65）、+1 LocalType/token、+1 错误码；**无新 opcode**（全部 helper 路由，同 A4–A8 模式）。

**核心设计决策（支点）**：

> **Any = 装箱搬运类型：句柄条目直存原生 Cangjie `Any`；唯一算子 = `is` / `as`**（延用仓颉 Any 语义本体——无动态调用、无计算、无等值）。

- **装箱（box）**：把**可转集内**的值放入不可变盒——值型 = 拷贝进盒（Cangjie 装箱语义本体，宿主侧分配）；引用型 = 存引用（零拷贝）；
- **`is`**：盒内容与目标类型的运行期问答（0/1，**永不失败**——集合外类型回答 false）；**`as`**：转型（命中取值；未命中 → 错误码 **22**）——Cangjie `as` 异常语义的码化；
- **零 §9.15 耦合**：box = 分配型（不可变）、is/as = 纯读 / 条件分配——**无变更型来源、不触发 deopt 禁令**；重放安全沿用 I8"重复分配等值对象"论证；
- 备忘记要（m2 §13.7）全部落实，两处精确化：① `3=Unit` 前端不发射装箱点；② **容器转型依赖仓颉泛型的运行期信息（前提 P2，§9）**。

**新增概念一览**：

| 概念 | 既有对应 | 增量 |
|---|---|---|
| Any 类型 | 边界 `Any`（Marshal，仅桥） | 世界内 LocalType 15 / token 12 |
| 装箱 | 无（世界内类型静态封闭） | H63 `any_box`（分配型） |
| 类型问答 | M2 §4 验签（边界一次性核对） | H64 `any_is` / H65 `any_as`（运行期、可反复） |
| 错误码 22 | 7 = 值转型（静态转换失败） | 22 = **动态转型失败**（`as` 未命中） |

## §1 Any 表示

**运行时表示**：句柄条目 `{tag=12, box: Cangjie Any}`——`box` 就是**原生 Cangjie `Any` 值**（冻结决策 ④ 复利：句柄表天然能存它，零新机制）。装箱语义 = Cangjie 语义本体：

| 被装箱值 | 盒内容 | 成本 |
|---|---|---|
| 值型（Int64/Float64/Bool） | **拷贝**（此后与原件无关联） | 宿主侧分配（分配型语义） |
| 引用型（String/Decimal/…/List/Map） | **引用**（共享对象，任何一侧修改对他侧可见——本就是 Cangjie 浅拷贝语义） | 零拷贝 |

- **LocalType 15 = Any**（句柄型，恒非空，§3.2 空安全规则同）；token 12；
- **可转集（初版冻结）**：LocalType `0–8、10–11`（Int64/Float64/Bool/Unit/String/Decimal/DateTime/Duration/Range/List/Map）——其中 `3=Unit 无装箱发射点`（前端不产生）；`9=Regex、12=Closure、13=HostClosure、14=HostObject 分期排除`（§12）；
- **不可二次装箱**：15 不在可转集内（`any_box(15, …)` 不可发射，前端拒绝）——盒不套盒（如需嵌套载荷 → 宿主类包装，M2 §11）；
- **能力面（冻结）**：持有 / 传参 / 存储（局部、容器元素）/ 返回 / `is` / `as` ✓；**运算、比较、等值（含 `EQ_H`）、成员访问、调用 ✗**（——15 型表达式上出现即编译错误，提示"先 `as`"；这是仓颉 Any 本体语义，不是本稿的缩减）。
- 生命周期：句柄路径 B/C/D 照 M1 §8.1（装箱结果 = 窗口分配【分配型】；逃逸/保活/清理全套沿用）。

## §3 前端语言面

**类型**：`Any` 可声明为局部 / 参数 / 返回（LocalType 15）；HostObject 字段类型**不扩展**至 15（§12）。

**装箱插入点（类型驱动，全部静态可知）**——源表达式类型 ≠ 15 而目标位置要求 15 时，发射 `any_box(类型码, expr)`：

1. 赋值/初始化 Any 槽（`let a: Any = expr`）；
2. Any 参数实参；Any 返回（`return expr`）；
3. 容器元素类型为 Any 时的元素写入（`LIST_APPEND`/`LIST_SET`/`LIST_INSERT`/`MAP_PUT` 前）——**异构容器的实现基础**。

**拆箱与问答**：`expr is T` / `expr as T`（T ∈ 可转集）：

- 左侧静态类型为 15 → 发射 H64/H65；左侧静态类型非 15 → 按静态类型关系处理（上行零操作；不相容 → 编译错误）——**helper 只为动态路径存在**；
- `as T` 的结果类型 = T（可继续参与 T 的全部既有运算——"先 as 后算"是唯一计算路径，延用仓颉）；
- 目标 T 不在可转集（如 `as Closure`）→ 编译错误（本版）。

**异构容器**：`List<Any>` / `Map<String, Any>` / `Map<Int64, Any>` 声明支持——容器大类型仍为 10/11，**元素/键值类型为前端/桥的静态知识**（外置惯例，M1 §11.7）；元素读写 cell 即盒句柄（`GET_IDX`/`GET_KEY` 返回值直接是 15 型表达式，无需转换）；`Map<Int64, Any>` 的 Int64 键沿用既有键机制。

**禁止面（编译错误）**：15 型表达式上的任何运算/比较/等值/成员访问/调用；`any_box` 的二次装箱；非可转集的 `is`/`as` 目标。

## §4 Marshal 与边界（§8.2.1/§8.2.2 的 M3 行）

| 签名位置 | 接受的宿主值 | 转换 | 失败 |
|---|---|---|---|
| 参数 `Any` | **任意宿主值**（含闭包、宿主类实例、任意对象） | 装箱入条目（存放原生 `Any`）→ cell = 句柄 | 19（null——与句柄恒非空不变式一致） |
| 返回 `Any` | —— | `get` → 原生 Cangjie `Any` 原样返回宿主 | —— |

- **"持有可通行、问答按可转集"**：宿主 Any 夹带的集合外类型（宿主类实例、闭包等）可**不透明持有与转发**（安全），但世界内 `is` 恒 false、`as` → 22——**干净收场，无走私路径**（12/13/14 的转型已于可转集排除）；
- 实施注记：M1 §8.2.1 表增 `Any` 行；§2 错误码映射 `1–22`。

## §5 指令与 helper（执行语义）

**helper 表（M3 实施时登记入 M1 §6；编号接 H62）**：

| H | 名称 | 签名 | 语义 | 失败 |
|---|---|---|---|---|
| H63 | `any_box` | `(typecode: u8, cell) → h` | **分配型**：值型 → 拷贝装箱（宿主分配）；句柄型 → fetch 后存引用 | 6, 8, 16 |
| H64 | `any_is` | `(h, typecode: u8, aux: u16) → 0/1` | 纯读：`box is T` 问答；集合外类型 → **0（非错误）** | 8 |
| H65 | `any_as` | `(h, typecode: u8, aux: u16) → cell` | **条件分配型**：命中 → 值型拆箱直返 / 句柄型按引用 pin（登记 1 槽，同 H61 模式）；未命中 → 22 | 8, 16, 22 |

**类型描述符**（H64/H65 的第二/三实参）：`typecode` = 主类型码（LocalType 编码）；`aux` = 容器附加码——`List(10)`：aux = 元素类型码；`Map(11)`：aux = `(键码 << 8) | 值码`；其余类型 aux = `0xFFFF`。**typecode 以 cell 形式压栈传递**（helper ABI 无立即数，同既有模式）。

**容器转型的元素/键值校验（前提 P2）**：`as List<Any>` / `as Map<Int64, Any>` 的运行期检查需要仓颉泛型的**运行期类型信息**（reified）——命中条件 = "是 List 且元素类型一致"；若实现环境的泛型信息不可用，退化为**不校验元素类型 + 宿主契约**（§9）。

**lowering（与 CALL_HELPER 同款）**：`any_box` / `any_is` / `any_as` 全部 = `call H6x` + 汇编器自动尾随 `CHECK_ERR`（I3）；机器码无新模式（I8 自动满足）。

**分配型清单同步（实施注记）**：M1 §1/§6/§8.1 的分配型枚举 +H63、H65（句柄型命中时）；`hwCap` 估计按装箱/转型点的静态类型编译期计入（§9.6 扩容兜底照旧）。

## §6 安全模型（继承 + 增量）

| 机制 | 语义 |
|---|---|
| **重放安全** | box = 分配型且盒不可变；is/as 纯读（`as` 命中句柄型时含 pin——分配型）⇒ **重放重建等值盒，可观察语义不变**（I8 论证原样）；**不触发 §9.15 deopt 禁令、不置 flags.bit0** |
| **纯度** | 全部新增操作无副作用（盒不可变、无跨调用状态）——不触碰 §8.3 纪律 |
| **GC** | 条目持原生 `Any`——其内部引用由仓颉 GC 经条目扫描保活 ✓；无新边界 |
| **失败即终止** | 22 写槽 → `CHECK_ERR → BAIL` 收敛 epilogue（I3/I4 原样）；`is` 永不失败（设计如此） |
| **并发** | 盒不可变 ⇒ 跨线程只读天然安全；盒子经句柄表条目持有，槽追加同步保护沿用 §9.7 |
| **卸载（M1 §8.7）** | 盒为 per-call / 窗口资产、无常量——**无交互** |
| **容量（真实债务）** | 值型装箱 = 每次 1 槽 + 宿主分配——Any 密集循环触发 **16（峰值容量错误）**；缓解沿 M1 §9.6 三手段（容量配置/拆分调用/限并发），**装箱点编译期可知 ⇒ 容量预算可静态对账** |
| **禁走私** | 集合外类型不可 `as`（22）⇒ 无法经 Any 绕过 M2 §11 类界（14）或 §4 验签（13） |

## §7 三引擎一致性（I7)

- H63–H65 为**共用仓颉实现**（@C 薄入口 + 普通 Cangjie）；装箱/问答/转型序列确定且单实现 ⇒ 三引擎**结构性一致**；
- `is`/`as` 的判定 = 仓颉运行期类型系统行为——跨平台由同一 std 保证（与 T1/T11 同一论证）；容器转型另受 P2 约束（§9）；
- **差分口径**：确定性数据（值型/基础引用型 + 异构容器）× 三引擎 → 结果/错误码（22 含 site）/site 逐位一致。

## §8 性能与容量

- **装箱成本**：值型 = 1 次条目 + 1 次宿主分配（拷贝）；引用型 = 1 次条目（零拷贝）——Any 密集路径的主要成本即此项；
- **is/as 成本**：一次运行期类型判定（+ 容器时的元素/键值判定）；`as` 命中句柄型时的一次 pin；
- **M3.1 优化展望（不在本文）**：小值盒缓存/装箱点去重（盒不可变 ⇒ 可安全共享，仅优化不改语义）；静态可判定的 `is`/`as` 前端折叠（当前已做静态路径免 helper）；
- **hwCap 对账**：装箱/转型点的类型静态可知 ⇒ 汇编期计入估计（M1 §9.6）。

## §11 JSON 字面量（v0.2 增篇）

**需求**：源语言支持 JSON 字面值——求值自动初始化为 `fountain::f_data.json.JsonValue` 的子类（对象 → `JsonObject`，数组 → `JsonArray`），并经 `fountain::f_data.path` API 访问内部数据。**零世界内新机制**：常量 kind 11（新增）+ HostObject 通道（M2 §11）+ 预定义函数通道（M2 §8.4）的组合。

**符号（冻结）**：**裸反引号 `` `…` `` = JSON 字面量（形态一）**——本语言唯一原始串定界形态；**v0.3 增直写形态（形态二：`{…}`/`[…]`，见下）**，两形态等价并存：

- 风格依据：与正则 `/pattern/flags` 一致（**专属定界符、无标签**，M1 §11.9 先例）；反引号此前未占用；
- 词法：`` ` `` 开 `` ` `` 闭，允许跨行（JSON 常多行）；内容**零宿主转义**（`"` 与 `\` 原样保留——JSON 自身转义由 JSON parser 消费，恰好一层）；
- **否决备选**（决策注记）：带 `json` 标签形式——本语言全部字面量均为"专属定界符、无标签"，且反引号无其它用途，标签徒增词法两义；**占用声明**——反引号自此为 JSON 专属，未来如需其它原始文本用途另择定界符，不回收反引号；字符串侧原始串已由 M1 §8.8（v0.14）以 `#`×n 定界成文——与本占用不冲突；
- **转义闭环**：JSON 字符串值内需反引号字符 → 用 JSON 层转义 `\u0060` 表达（不改串语法）。

**直写形式 `{...}` / `[...]`（v0.3 新增，冻结）**：

- **语法**：`{…}`（对象）与 `[…]`（数组）可直接书写为 JSON 字面量，**允许跨任意多行**（成员/元素逐行书写为其主用法）；与反引号形式**等价并存**——同一常量模型（kind 11）、同一静态类型与加载期规则；无 `.fbc` 格式变更。
- **词法消歧（冻结）**：
  - `{`：其后的**首个非空白字符**（空白含换行）为 `"` 或 `}` → **JSON 对象**（`{}` = 空对象——此前为非法输入，无冲突）；否则按既有闭包字面量 `{ args => body }` 解析（闭包参数均为标识符，天然不冲突）。即 `{` 与首个成员之间**不允许注释**（注释在 JSON 文本中无法表示）；
  - `[`：位于**表达式起始**（前一 token 非操作数结束符——标识符/字面量/`)`/`]` 等）→ **JSON 数组**（`[]` = 空数组）；位于操作数之后（`list[i]`、`map[k]`）→ 既有下标语法，原义不变。
- **内容与多行**：段内换行即 JSON 空白（结构、嵌套任意跨行）；**原始 JSON 文本、零宿主转义**（同反引号形式）；**不识别源语言注释**——段内 `//`、`/*` 均按 JSON 文本参与解析（`"http://x"` 字符串值中的 `//` 是内容本身）；非法/未闭合 → **源编译错误**（同反引号主防线，消息含位置）。词法上直写段整体为一个 JSON 字面量 token。
- **词法保护（对 M1 §8.5 阶段①的增量；含 v0.2 缺口修复）**：反引号 JSON 段与直写 JSON 段一并并入保护阶段——段内 `//`、`/*`、引号、`{`、`}`、`>|` 不参与注释识别与配对；段取界为 **JSON 字符串感知 + 括号配平**（`{"a":"}"}`、`["]"]`、嵌套 `[{…}]` 正确取界）；无匹配闭合 → 不构成段，交解析器报错。**（v0.2 未成文反引号 JSON 段的保护——本版一并补齐，防止 `"http://x"` 类内容被注释剥离破坏。）**
- **换行规范化**：两形式统一 CRLF/CR → `\n` 后再作为 payload（与 M1 §8.8 同规）——跨平台编译产物逐字节一致。
- **类型 / 常量 / 加载期**：`{` → `JsonObject`、`[` → `JsonArray`；常量 kind 11（payload = 规范化后的原始 JSON 字节）；加载期一次解析——均照上文同规则，不重复。

**编译期**：

1. 词法识别 JSON 段（反引号串体 / 直写 `{...}`、`[...]` 段）→ **按 JSON 语法解析一遍**：非法 → **源编译错误**（消息含位置与 JSON 错误描述）——主防线；
2. 顶层结构决定**静态类型**：`{` → `JsonObject`、`[` → `JsonArray`（"自动初始化为子类型" = 编译期标注；子类名 = 前端静态知识，M2 §12.4 `typeRef` 模式原样复用）；
3. **标量顶层**（`123` / `"s"` / `true` / `null`）本版**编译错误**（列 §12 开放问题）；
4. 发射常量引用：**kind 11 = Json**（payload = u32 长度 + UTF-8 原始字节串——与 kind 3 String 编码同构；**原始字节即 payload，解析在加载期**）。

**格式变更（M3 版本内追加，verMajor 3）**：常量 kind **11 = Json**。
实施注记（跨文档同步）：m2 §1"常量 kind 不新增 11"的表述**限定于 HostClosure**（闭包不可序列化语义不变）；kind 11 由本篇使用（m2 v0.8 已同步措辞）。

**加载期**：桥对每个 kind 11 常量**实例化一次**——调用 `fountain::f_data.json` 解析器构建 `JsonObject` / `JsonArray` 实例 → 登记 ConstTable（**路径 A**：跨调用同 ID、单元生命周期、**不可变**）——与 Regex（kind 10）完全同构；防御性再校验失败 → **加载期拒绝**（沿 kind 10 先例；理论上编译期已过）。

**类型与句柄**：JSON 值 = **宿主类实例** ⇒ 经 **HostObject 通道（M2 §11）**持有（token 14 句柄；条目含宿主对象引用；具体子类为前端静态知识）。常量不可变 ⇒ 重放 / 差分安全 ✓；**不可世界内构造或修改**（属宿主或后续增量，列 §12）；跨桥（参数 / 返回 / retType=14）照 M2 §11 规则。

**访问 API（`fountain::f_data.path`）**：

- 纯宿主库 → 经 **M2 §8.4 预定义函数通道**注册（快照语义；函数名与签名由宿主库定义，规范只约定注册模式）；JSON 句柄（14）作参数直接可传；
- **推荐形态**：节点取值为**类型化 getter**（返回 14 句柄或具体值——`JsonObject`/`JsonArray`/`Int64`/`String`…）；异构取值可返 **`Any`（§0–§10 通道）**，用 `is`/`as` 取具体；
- **边界约束（设计须知）**：`Any → 14` 的转型**不在本版可转集**（§1 分期）——因此 path API 设计应优先**类型化 getter 返回 14 句柄**，避免要求"从 Any 里取 JSON 节点"；该转型需求已列入 §12 二期转型集配套；
- 成员访问语法糖（M2 §12.4）与本篇**无交互**（JSON 访问走函数通道，语义零新增）。

**安全 / 对账（全部白捡）**：常量不可变 ⇒ 重放与三引擎一致 ✓；无装箱 churn（常量路径零分配）；fail-fast 照旧；卸载（M1 §8.7）随单元回收 ConstTable ✓；GC 经 ConstTable 保活 ✓。

**测试**：T41（§10）。
