# 验证：optimize-call-alloc2

## 1. 数据：未测得显著收益

`CallPathBench` B1（`{ n: Int64 => n + 1 }`，5 轮取最小）：

| 臂 | L1（ns/call） | Q1（calls/s） |
| --- | --- | --- |
| 改前（本日更早基线） | 3036 | 329k |
| 改后（两轮） | **2975** / 5516 | 336k / 181k |

快模式 3036 → 2975（**−2.0%**），慢模式 +2.3%，均在噪声内且低于 MOV(3%)。
**本轮不宣称加速**；保留理由是「每次调用少一个闭包 + 一次间接调用（零实参再少一个数组）」，
且 `makeRetUnboxer` 仍保留（测试在用），生产路径改走 `unboxRet` 方法。
