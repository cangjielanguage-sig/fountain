# Spec Delta

## Purpose

给方言补两项数值能力：**Int64 幂运算 `**`**（语法与限制对齐仓颉）与**浮点/十进制科学计数法**
（含仓颉允许的前导点形态）。

## ADDED Requirements

### Requirement: Int64 幂运算 `**`

`**` SHALL 只接受 `(Int64, Int64) → Int64`；其他类型组合在**编译期**以 `TYPE_MISMATCH` 拒绝
（与 `%` 同风格），消息含两侧类型。

- 优先级 **4**、**右结合**（高于 `*`/`/`/`%`，低于一元 `-`）：
  `2 ** 3 ** 2` = `2 ** (3 ** 2)` = 512；`-2 ** 2` = `-(2 ** 2)` = -4。
- 指数为负（含字面量）时 SHALL 以 `ERR_ARG_MISMATCH(14)` 在**运行期**拒绝（仓颉侧指数为 `UInt64`，负值类型上不可表达；方言无无符号类型，故以运行期码表达该限制）。
- 运行期指数为负 SHALL 以 `ERR_ARG_MISMATCH(14)` 失败。
- 结果溢出 SHALL 以 `ERR_OVERFLOW_I64(3)` 失败（对齐仓颉"静态可判编译期报错、否则运行期抛异常"）。
- `x ** 0` = `1`、`0 ** 0` = `1`、`0 ** n` = `0`（`n > 0`）。

#### Scenario: 基本与右结合

- **WHEN** 执行 `{ => 2 ** 10 }`、`{ => 2 ** 3 ** 2 }`、`{ => -2 ** 2 }`、`{ => 0 ** 0 }`
- **THEN** 分别返回 `1024`、`512`、`-4`、`1`

#### Scenario: 溢出与负指数

- **WHEN** 执行 `{ => 2 ** 63 }`（常量）或运行期算出 `2 ** n`（`n = 63`）
- **THEN** 以 `3` 失败；`{ x: Int64 => 2 ** x }` 传 `-1`（或字面量 `2 ** -1`）时以 `14` 失败

#### Scenario: 类型限制

- **WHEN** 写 `1.5 ** 2`、`"a" ** 2`、`2 ** 1.5`
- **THEN** 编译期 `TYPE_MISMATCH`

#### Scenario: 三引擎一致

- **WHEN** 同一单元在解释器 / x86_64 / aarch64 执行
- **THEN** 结果、错误码、site 逐位一致（幂走共享 helper H77）

### Requirement: Float64 / Decimal 科学计数法字面量

数字字面量 SHALL 支持科学计数法，语法与仓颉一致：

- 十进制指数用 `e`/`E`（底 10），指数可带正负号：`3e2`、`1e-3`、`1.5e3`、`2.4E-1`；
- **前导点**形态 SHALL 支持：`.5`、`.5e2`、`.5e2f64`；
- 带 `f64` 后缀 ⇒ **Float64**；无后缀且含小数部或指数部 ⇒ **Decimal**（方言既有约定）；
- 无小数部且无指数部 ⇒ Int64（`3` 不变）；
- 非法形态 SHALL 词法错误：`1e`、`1e+`、`.` 单独、`1.5f32`、`1.5e2f32`。

#### Scenario: 两类类型的指数形态

- **WHEN** 执行 `{ => 1.5e3 }`（Decimal）、`{ => 3e2 }`（Decimal）、`{ => 1e-3 }`（Decimal）、
  `{ => 1.5e3f64 }` / `{ => .123e2f64 }`（Float64）
- **THEN** Decimal 侧按精确十进制构造（`1.5e3` = `1500`、`1e-3` = `0.001`），Float64 侧为 IEEE 值

#### Scenario: 前导点与错误面

- **WHEN** 写 `.5`、`.5e2`、`.5e2f64` / 写 `1e`、`1.5f32`
- **THEN** 前者合法（Decimal/Decimal/Float64）；后者词法错误（`ILLEGAL_CHARACTER` / 数字紧邻标识符的诊断）
