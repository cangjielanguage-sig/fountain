## §0 计划总则（M3 附加）

1. **零回归**：每步提交前跑 M1 + M2 全量（含差分）——M1/M2 产物与语义必须零变化。
2. **三态兼容**：M3 加载器对 v1/v2/v3 分别按规则集校验；v3 规则集 = LocalType 0–15 + H66–H68/H73–H75 值域 + kind 11。

4. 其余总则（红→绿→重构、证据口径、测试落点）同 plan-m1.md §0。

## §3 顺序约束与风险

1. **硬顺序**：R2（kind 11 与 f_data 依赖）先于 R3.6–R3.9；R4.1–R4.5（Any）与 R4.6–R4.9（JSON）可并行；R4.10–R4.12（特化）最后做且独立可回退（纯加速）。
2. **P2 依赖**（M3-2）：R4.5 先以最小用例确认 reified 行为；退化路径必须显式且可测。
3. **编号冲突两处——均已裁定并实施（2026-10-11）**：① **T59 重号**——m3 侧改 **T61**（m2 侧保持 T59；m3 规格、design-m3 与本计划已同步）；② **JSON helper 编号**——JSON 面顺延为 **H73–H75**（避让 M1 已占用的 H72 `regex_replace_range`；m3 规格「接 H71」已订正为「编号顺延」）；本计划已按 H73–H75 排期。
4. **返工风险最小化**：特化（R4.10–R4.12/R5.4–R5.5）是唯一「可整体回退」的专项——若收益实测不达标，按 §13.4 渐进交付只留第 0 步。
5. **M1/M2 零回归**：每步跑 R0.3 基线对照；任何 M1/M2 产物差异按阻塞缺陷处理。
