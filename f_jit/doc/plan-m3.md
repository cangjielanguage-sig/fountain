## §0 计划总则（M3 附加）

1. **零回归**：每步提交前跑 M1 + M2 全量（含差分）——M1/M2 产物与语义必须零变化。
2. **三态兼容**：M3 加载器对 v1/v2/v3 分别按规则集校验；v3 规则集 = LocalType **0–19**（15=Any、16–19=JSON）+ H66–H68/H73–H75 值域 + kind 11。
3. **特化专项单独开关**：「强制通用 / 强制特化」双路径跑全量差分（T30–T36 + T56），特化 ≡ 通用逐位。
4. 其余总则（红→绿→重构、证据口径、测试落点）同 plan-m1.md §0。
