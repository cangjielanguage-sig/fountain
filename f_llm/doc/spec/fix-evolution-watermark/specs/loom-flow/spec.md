# Spec Delta

## ADDED Requirements

### Requirement: 水位线只覆盖已处理素材

演进结束时，水位线 MUST 推进到「本轮实际参与处理的素材中最大的 `at`」，MUST NOT 直接推进到当前时间；
没有带时间戳的素材时 MUST 保持原有「按轮次推进」行为。水位线 MUST 单调前进，MUST NOT 后退。

#### Scenario: 素材少于单轮上限

- **WHEN** 3 条素材 `at = 10/20/30`，`now = 5000`
- **THEN** 水位线是 `30`（下一轮仍会看到 `at > 30` 的新素材）

#### Scenario: 素材超过单轮上限

- **WHEN** 本轮只取到 500 条（最大 `at = 200`），库里还有 `at = 201…900` 的素材
- **THEN** 水位线是 `200`，下一轮仍能取到 `201` 之后的素材，不会被跳过

#### Scenario: 只有知识文档

- **WHEN** 本轮素材全是 `at = 0` 的知识条目
- **THEN** 水位线按 `now` 推进（知识本身由「已消费 docId」去重）
