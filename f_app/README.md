# f_app

**注意⚠️**： 必须导入本模块`import fountain::f_app.*`调用`std.env.atExit`注册的进程退出函数才能生效。
本模块为kill 15和CTRL+C注册了信号处理函数。如果不注册信号处理函数也不导入本模块，atExit注册的进程退出函数不会生效。
