# fountain

## 介绍
一个用于服务器应用的综合工具库，零配置文件、环境变量和命令行参数配置、约定优于配置、只需要开发动态链接库、fboot负责加载、初始化并运行。

### 本项目的所有动态链接库
- 如果仅仅是开发使用，可以使用cjpm run当前依赖fountain的项目，就自动加载了。
- 如果是在Linux服务器环境运行，最好将本项目编译的动态链接库都加入环境变量LD_LIBRARY_PATH。

### fboot
- 把fboot加入PATH环境变量
#### 动态fboot
1. 如果fboot有启动参数，则扫描启动参数指定的路径并加载找到的所有动态链接库，完成初始化。
2. 如果fboot没有启动参数，且没有在当前目录发现cjpm.toml，则扫描当前目录及子目录并加载找到的所有动态链接库，完成初始化。
3. 如果fboot没有启动参数，且在发现当前目录cjpm.toml，会加载./target目录下的所有动态链接库，并扫描所有aspect类型，按照注解的切面规则向对应的函数添加宏注解@Pointcut。
